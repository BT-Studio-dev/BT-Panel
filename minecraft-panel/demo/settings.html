Deployment notes

BT Panel site

Add the site, set the document root to public/, choose PHP 8.1+ and enable the pdo_sqlite extension. Disable the default PHP “anti-cross-site” rewrite for /api/ if you add custom location rules.

Ports & firewall

Open the Minecraft game port (default 25565/tcp) and, if you use it, the RCON port in BT Panel → Security. Wings does not need to be installed for local servers.

Backups & updates

Backups land in storage/backups. Include config.php and storage/panel.sqlite in your BT Panel site backup, and keep the folder outside git.

Operating a Minecraft server means you are responsible for the Minecraft EULA and for keeping Java updated.
